# Design

## Decisions

- **이슈 트래커의 이름은 생성 안내에 고정하지 않는다.** 이슈 정책은 소비 프로젝트가 소유한다. 생성 안내는 "프로젝트의 이슈 트래커(GitHub 이슈 등)"로, 이 저장소의 규칙은 GitHub 이슈로 적는다.
- **테스트 우선은 apply 지침에 둔다.** 계획의 체크박스가 아니라 task를 구현하는 방법이다.
- **이미 보관한 change는 고치지 않는다.** 당시 기록이다.
- **기존 프로젝트의 `openspec/config.yaml`은 고치지 않는다.** 프로젝트 소유라는 계약을 유지한다.
